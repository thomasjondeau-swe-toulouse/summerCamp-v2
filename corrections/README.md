# Corrections

Un dossier par étape du camp. Ce sont les versions **terminées**, écrites par le formateur.

| Dossier | Correspond à |
|---|---|
| `step-1-starter` | Le point de départ (= le contenu initial de `familytask`) |
| `step-2` | Fin de l'atelier 1 |
| `step-3` | Fin de l'atelier 2 (front-end) |
| `step-4` | Fin de l'atelier 3 (back-end + base) |
| `step-5` | Fin de l'atelier 4 (comptes et connexion) |
| `step-6` | Fin de l'atelier 5 (assistant IA) |
| `step-7` | Fin de l'atelier 6 (tests) |
| `step-8-final` | Fin de l'atelier 7 (déploiement) — l'app complète |

## Comment s'en servir

**Bien :** ouvrir le fichier correspondant, comparer avec le tien, comprendre ce qui diffère.
**Mal :** copier-coller. Ce que tu recopies, tu ne l'apprends pas.

## En dernier recours

Si ton app est vraiment cassée et que tu ne peux plus avancer, demande au formateur.
Il pourra te faire repartir de la correction du jour :

```bash
rm -rf familytask && cp -r corrections/step-5 familytask
```

⚠️ Cette commande **efface ton travail**. Elle ne s'utilise qu'après un `git push`,
et seulement sur décision du formateur.
