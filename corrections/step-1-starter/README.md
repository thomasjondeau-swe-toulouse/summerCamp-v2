# step-1-starter — le point de départ

**C'est la copie initiale de `familytask/`**, telle qu'elle est le lundi matin avant que tu y touches.

**Contient :** la configuration Docker et une app minimale qui affiche un écran de bienvenue.
La connexion à la base est déjà écrite (`DATABASE_URL`, `engine`) mais pas encore utilisée.

**Ne contient pas :** de todo-list, d'API, de comptes. C'est normal.

Il est là si tu veux voir d'où tu es parti, ou repartir de zéro.

## Lancer ce dossier

```bash
docker compose up
```

Puis clique sur **Open in Browser** (ou onglet **PORTS** → ligne **5173** → 🌐).
Swagger, la documentation de l'API, est sur le port **8000**, chemin **`/docs`**.

> ⚠️ Ce dossier est un **corrigé** : il sert à comparer, pas à travailler dedans.
> Ton code à toi est dans `familytask/`.
