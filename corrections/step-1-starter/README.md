# step-1-starter — le point de départ de l'**atelier 1**

**Contient :** Docker + une app minimale qui affiche un écran de bienvenue.
**Ne contient pas :** rien de plus. L'atelier 1 ne demande **aucune ligne de code**.

**Ce que tu fais dans l'atelier 1 :** installer VS Code + Docker, cloner ce dossier, le lancer.
Si l'écran de bienvenue s'affiche, tes installations sont bonnes. C'est tout l'objectif.

## Lancer ce dossier

```bash
docker compose up
```

- L'app : http://localhost:5173
- L'API : http://localhost:8000/docs
